# VectorFM

A wavetable / phase-modulation oscillator for the **Korg NTS-1 digital kit mkII**, built with the logue SDK v2.

Six procedural wavetables you can scan continuously, phase-modulated by a sine modulator, across two detuned oscillators you can morph between, followed by a wavefolder and soft saturation. The NTS-1's shape LFO and a built-in slow movement LFO both sweep the wavetable.

## Download & install

1. Go to [**Releases**](https://github.com/TwistedGenetics/Vector_Synth/releases/latest) and download `VectorFM.nts1mkiiunit`.
2. Open **KORG KONTROL Editor** with the NTS-1 mkII connected (firmware 1.3 or later recommended).
3. Drag the file onto the **oscillator** list, then press **SEND**.
4. Select VectorFM with the OSC button.

## Controls

| Control | Parameter | Range | What it does |
|---|---|---|---|
| Knob A | SCAN | 0–1023 | Sweeps through the 6 wavetables: sine → triangle → saw → square → formant → harmonic stack |
| Knob B | FM | 0–1023 | FM intensity (squared curve, so the first half of the knob is subtle) |
| Edit 1 | FM RATIO | 0.5, 1, 1.5, 2, 3, 4, 5, 7, 8 | Modulator frequency relative to the note. Whole numbers stay harmonic; 1.5 gives bell/metallic tones |
| Edit 2 | FM INDEX | 0–100 % | FM depth multiplier (in FDBK mode: modulator feedback amount) |
| Edit 3 | WAVEFOLD | 0–100 % | Sine wavefolder |
| Edit 4 | MORPH | 0–100 % | Crossfade osc 1 → osc 2. Osc 2 reads the wavetable 40 % further along, so it's a different timbre |
| Edit 5 | DETUNE | 0–100 % | Detunes the oscillators apart, up to ±25 cents (Reese territory near 100 % with MORPH at 50 %) |
| Edit 6 | SATURATE | 0–100 % | Soft (tanh-style) saturation, level compensated |
| Edit 7 | MOVEMENT | 0–100 % | Built-in LFO on the wavetable scan: rate 0.05–2 Hz and depth rise together |
| Edit 8 | MODE | CLSC, FDBK, CROS, FOLD | Synthesis variation (below) |

Edit parameters: hold **OSC** and turn the encoder to choose, then use Knob B to set the value.

The NTS-1's **shape LFO** (the LFO routed to shape) also modulates the wavetable scan.

### Modes

- **CLSC (classic)** — sine modulator phase-modulates the wavetable. Clean, DX-meets-wavetable.
- **FDBK (feedback)** — the modulator feeds back on itself (amount = FM INDEX), giving gritty, noisy, saw-like FM. FM knob sets depth on its own.
- **CROS (cross-mod)** — osc 2 modulates osc 1 (and a little back again). FM RATIO sets osc 2's pitch relative to osc 1. Turn MORPH to hear osc 2 itself.
- **FOLD (fold-FM)** — classic FM pushed into a harder, always-on wavefolder. For aggressive basses.

## Test checklist (by ear on the hardware)

Start from the default settings (everything 0, FM INDEX 50 %, RATIO 1, MODE CLSC).

- [ ] **Tuning** — play A4 against a tuner: should read 440 Hz.
- [ ] **Knob A** — smooth sweep sine → triangle → saw → square → nasal formant → organ-like stack, no clicks or steps.
- [ ] **Knob B** — nothing at 0, gradual brightening, metallic/clangy at full.
- [ ] **FM RATIO** — with B up, 1/2/3/4… stay pitched; 1.5 and 0.5 sound inharmonic/sub-heavy.
- [ ] **WAVEFOLD** — adds buzzy upper harmonics, stays pitched.
- [ ] **MORPH + DETUNE** — MORPH 50 %, DETUNE up: slow beating that becomes a wide, chorused/Reese sound.
- [ ] **SATURATE** — thickens and compresses; volume roughly steady.
- [ ] **MOVEMENT** — timbre slowly sweeps on its own; faster and deeper as you raise it.
- [ ] **Shape LFO** — route the LFO to shape: the wavetable scan wobbles.
- [ ] **MODE** — each of CLSC / FDBK / CROS / FOLD sounds distinctly different with B around halfway.
- [ ] **High notes** — top octave sounds clean (no whistling aliases) with B at 0.
- [ ] **Everything at max** — loud and nasty, but no dropouts, crackles, or the unit stopping.

## Building

GitHub Actions builds and tests the unit on every push (the latest build is under the **Actions** tab, as an artifact). Releases are automatic: when the `.version` in `vectorfm/header.c` changes (e.g. `0x00010001U` = 1.0.1) and is pushed to main, Actions builds, tests and publishes a new Release with the unit file. Pushes that keep the same version refresh that Release's file.

To build locally instead (no Docker needed, Linux or macOS):

```sh
./build.sh
.github/workflows/build.yml   CI build + release
```

This downloads ARM GCC 10.3 (xPack) and the logue SDK into `.deps/` on first run, then writes `dist/VectorFM.nts1mkiiunit`.

Desktop DSP tests (renders audio, checks tuning, levels, aliasing and zipper noise, writes demo WAVs to `test/out/`):

```sh
./test/run.sh
```

The wavetables in `vectorfm/tables.h` are generated by `tools/gen_tables.py` (6 shapes × 7 band-limited mip levels × 256 samples, int16).

## Layout

```
vectorfm/   header.c (parameters), unit.cc (SDK callbacks), synth.h (DSP), tables.h, Makefile, config.mk
tools/      gen_tables.py
test/       render.cc, run.sh
build.sh
.github/workflows/build.yml   CI build + release
```
